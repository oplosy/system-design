# Security policy

## Supported versions

The latest release gets security fixes.

## Reporting a problem

Use GitHub's [private vulnerability reporting](https://github.com/oplosy/system-design/security/advisories/new). Don't open a public issue. Say what is affected, how to reproduce it and what an attacker gains.

## What is in scope

How the app protects itself is described under [Security](README.md#security) in the README, and what it doesn't cover under [Known limits](README.md#known-limits).
